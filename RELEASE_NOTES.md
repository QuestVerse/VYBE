## ZYX v1.1.0 — first stable release

A customizable music player for iPhone and Android, built around how your music *looks* as much as how it sounds.

### Highlights
- **Vinyl player** — a spinning record with a curved time bar, smoke background tinted by the album art, and synced lyrics.
- **Live themes** — Smoke, Snow, Sakura, Aurora, Rain, Neon and more, with moving backgrounds and Liquid Glass style controls.
- **Apple Music–style dock** — glass tab bar with a sliding highlight, and a vertical dock with a pill mini player in landscape.
- **Library** — liked songs, playlists, albums, and one-tap **Download all** for listening offline (the button turns green when everything is saved).
- **Trending** — weekly / monthly / yearly charts by country.
- **Built-in log** — Settings › Log, so you can send a bug report in a few taps.

### Install
- **Android:** download `Zyx.apk` below and open it to install (allow installing from your browser if asked).
- **iPhone:** download `Zyx-unsigned.ipa` below and sign it with ESign, Sideloadly or AltStore.

> If you used a test build before, uninstall it and install this version once. From now on, updates arrive automatically inside the app.

### Known issues
- Some downloads are saved as larger files than needed; we're working on it.
- Downloads pause when the app is in the background.
- On some older iPhones the app may freeze for a moment; we are looking into it.

Found a bug? Open Settings › Log, tap share, and post it in the Discord #bug-report channel.
