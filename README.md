# VYBE

**Your music. Your vibe.**

VYBE is a modern music player for iOS and Android, built to make listening to music a beautiful experience.

### ✨ Features

- 🎵 Modern music player
- 💿 Animated vinyl-style player
- 🎨 Dynamic visual themes
- 🌌 Beautiful animated backgrounds
- 🎤 Lyrics support
- 📱 Designed for iPhone and Android
- 🎧 Offline listening

### 🚀 Project

VYBE is based on an open-source music player and is being customized and developed into its own experience.

### 📦 Platforms

- iOS
- Android
